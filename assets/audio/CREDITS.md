Only the files the game uses are kept here (`music/`, `sfx/`; git-ignored, rebuilt by the import tool). Where each one comes from is listed in
`tools/import_audio.py`. The full packs live in the git-ignored `asset_packs/`.

**Redistribution:** the Ririsaurus terms forbid redistributing the assets themselves. The audio files are
git-ignored and were removed from the repository history, so the repository does not redistribute them. Keep it
that way: never commit or upload files from `sfx/` or `music/`, and rebuild them locally with `tools/import_audio.py`.
